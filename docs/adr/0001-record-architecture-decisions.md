# ADR 0001: Record architecture decisions

- **Status:** accepted
- **Date:** 2026-10-10
- **Deciders:** @Tunaycel

## Context

Two or more people now work on this repo. Decisions made in chat are lost, and new people
cannot tell why the code looks the way it does.

## Decision

Lasting technical decisions are written as short ADRs in `docs/adr/`, numbered in order, using
[the template](../templates/adr.md). An ADR is never edited after it is accepted; a later ADR
supersedes it.

## Consequences

A few minutes of writing per decision. Reviews can point to an ADR instead of re-arguing it.
